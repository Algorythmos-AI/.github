### Client work

**[International Coalition for Human Rights](https://www.ichr-international.org)** — a trilingual
(English, العربية, Français) newsroom and CMS for a Geneva-based NGO, engineered and operated by Algorythmos.

### How we build

- **Verifiable by construction.** Data is pinned by commit and checksum, and apps refuse inputs that
  don't match their manifest.
- **Every change is reviewed and gated.** Pull requests only, CI on every change, and production
  releases promoted from `integration` to `main` under branch rulesets.
- **Secure defaults.** Secret scanning, push protection, dependency alerts and private
  vulnerability reporting on every public repository.
- **Multilingual from the start**, including right-to-left scripts.
